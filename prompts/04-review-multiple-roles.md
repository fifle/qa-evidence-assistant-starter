# Prompt 04 — Review from multiple roles

Ask your AI assistant to review the current implementation as:

1. Manual tester — is the report useful and honest?
2. Automation engineer — are follow-up ideas actionable?
3. Frontend developer — is the UI clear and maintainable?
4. Security reviewer — is redaction sufficient?
5. Future maintainer — is the code easy to extend?

Request a prioritized list of improvements (max 5 items).
